# Kestrel Remote

Consent-based Android device status and visible notification manager controlled by a Telegram bot.

## What it does
- Pair each Android device using a short-lived one-time code generated by the Telegram admin.
- Show device model, Android version, battery percentage, and last heartbeat.
- Send a visible Android notification to a paired device.
- Revoke a device from Telegram.
- Android polling runs only after the owner taps **Connect** and is shown as a foreground-service notification.

It does **not** collect keystrokes, SMS, call logs, contacts, files, camera, microphone, or location. It does not execute shell commands.

## 1. Telegram bot setup
1. Create a bot with BotFather and copy its token.
2. Get your numeric Telegram user ID.
3. Copy `server/.env.example` to `server/.env`.
4. Set `BOT_TOKEN` and `ADMIN_ID`.

## 2. Run the backend
Python 3.11 or newer:
```bash
cd server
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python main.py
```
The API listens on port 8000. For devices outside your LAN, deploy behind HTTPS (for example, a reverse proxy with a valid TLS certificate). Do not expose plain HTTP to the public internet.

## 3. Build the Android APK with GitHub Actions
1. Push this repository to GitHub.
2. Open **Actions** and run **Build Android APK**, or push to `main`.
3. Download `kestrel-debug-apk` from the completed workflow run's Artifacts section.

The workflow builds a debug APK. It is suitable for testing, not Play Store distribution.

## 4. Connect a device
1. Start the backend and Telegram bot.
2. In Telegram, send `/newpair`.
3. Open Kestrel Remote on the Android phone.
4. Enter the backend URL, e.g. `https://your-domain.example`, and the pairing code.
5. Tap **Pair device**, then **Connect**. Allow notifications if Android asks.
6. In Telegram, use `/devices`, `/status DEVICE_ID`, or `/notify DEVICE_ID message`.

Each device must be paired by someone with physical access to that device. The Android app displays an ongoing foreground-service notification while connected.

## Telegram commands
- `/newpair` — create a one-time pairing code (expires after 5 minutes).
- `/devices` — list paired devices.
- `/status DEVICE_ID` — show last reported status.
- `/notify DEVICE_ID message` — queue a visible notification.
- `/revoke DEVICE_ID` — revoke a device's API credential.

## Security notes
- Use HTTPS in production. Android cleartext HTTP is disabled by default.
- Keep `.env` private. Never commit it.
- Use a dedicated server, firewall, backups, and database access controls.
- The example uses a single admin Telegram ID and SQLite. For production, add reverse-proxy rate limiting, monitoring, database backups, and a stronger admin deployment process.
- Revoke a lost device with `/revoke DEVICE_ID`.
